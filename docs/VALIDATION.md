# 验证范围

## 已覆盖

- 合成数据上的坏道规则、质量分档、ICA 成功与失败降级、球面插值、平均参考、阻抗阈值、命令行失败隔离和数据契约。
- Ruff 检查与格式检查。包可构建，四个命令行入口可用。
- `uv.lock` 锁定依赖。CI 在 Python 3.11 和 3.12 上跑同一套检查。
- Parquet 往返保留 schema、数值、行组大小和压缩 codec；源文件 SHA-256 不变。
- 缺少命名电极时不终止，也不补猜坐标。

## 未覆盖

- 真实样本的端到端修复是否有效。这取决于已确认的单位和与帽型匹配的坐标。
- 低通道数的实机数据，以及真实阻抗文件。现有阻抗测试使用合成快照。

设置 `EEG_TEST_DATA` 可启用指向本地数据集的可选契约测试；未设置时相关用例跳过。合成测试可能触发 MNE 关于少量电极球面拟合、头半径和短记录滤波的警告。测试通过只说明实现符合约定。
