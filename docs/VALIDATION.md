# 验证记录

## 自动化与契约

- pytest 覆盖合成数据上的坏道规则、ICA 成功/失败降级、球面插值、平均参考、阻抗阈值、CLI 隔离和数据契约。
- Ruff 静态检查及格式检查。
- 包构建与命令行入口可用。
- `uv.lock` 锁定依赖，支持离线一致性检查。
- Parquet 读写往返保留 schema（含元数据）、值、行组大小与压缩 codec；源文件 SHA-256 不变。
- 标准 montage 对完整覆盖的设备可通过。缺少命名电极时不终止处理，也不补猜坐标；这些通道不参与球面插值。

## 尚未覆盖或需设备侧确认

- 真实样本的端到端修复有效性：依赖已确认的单位与适配帽型的坐标。
- 低通道数实机数据：当前以合成测试为主，需真实电极列表、采样率、单位与坐标。
- 实际阻抗文件：当前用合成快照测试输入契约。
- 外部 CI 多版本 Python 运行结果：工作流已配置，以托管服务结果为准。

合成测试可能触发 MNE 关于少量电极球面拟合、头半径及短记录滤波的警告；这些是需要设备数据进一步验证的数值限制，不将“测试通过”解释为真实修复质量验收。

## 暂定坐标试运行

- 使用独立 `configs/provisional.yaml`；正式设备配置不变。
- 完整坐标覆盖设备配置中的头皮通道并集。`Cb1/Cb2/Cbz` 使用模板别名 `I1/I2/Iz`。`F11/F12/FT11/FT12` 使用公布的 PAN 坐标（毫米换算为米），不使用相似变换结果。共同电极的配准残差不描述这 7 个位置。
- dry-run 可验证单位、坐标覆盖与输出路径。
- 真实修复仍受坏道比例上限与最少好道数约束；超限记录拒绝发布，不放宽阈值。
- 成功输出应核验源 SHA-256 未变、schema 与行数保持、时间戳及辅助通道保留。运行时不另存审计文件。
- 以上证明坐标覆盖和流程实现可运行，不证明帽型定位精度或真实信号修复质量。

设置 `EEG_TEST_DATA` 可启用指向本地数据集的可选契约回归测试。
