# 验证记录

## 已覆盖

- pytest 覆盖合成数据上的坏道规则、质量分档、ICA 成功与失败降级、球面插值、平均参考、阻抗阈值、CLI 隔离和数据契约。
- Ruff 检查与格式检查。包可构建，三个命令行入口可用。
- `uv.lock` 锁定依赖。
- Parquet 往返保留 schema、值、行组大小与压缩 codec；源文件 SHA-256 不变。
- 缺少命名电极时不终止处理，也不补猜坐标。

## 未覆盖

- 真实样本的端到端修复有效性。依赖已确认的单位和适配帽型的坐标。
- 低通道数实机数据，以及真实阻抗文件。当前阻抗测试使用合成快照。
- 托管 CI 的多版本 Python 结果，以托管服务为准。

合成测试可能触发 MNE 关于少量电极球面拟合、头半径和短记录滤波的警告。测试通过只说明实现符合约定，不说明真实修复质量已验收。

设置 `EEG_TEST_DATA` 可启用指向本地数据集的可选契约测试；未设置时相关用例跳过。暂定坐标的来源与适用范围见 [PROVENANCE.md](PROVENANCE.md)。
