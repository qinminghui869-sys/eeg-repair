# 实现边界

参数默认值以 [README](../README.md) 的修复参数表为准。阈值只写在 `algorithms.py`，配置里不再写一套。

## 和参考流程的差别

`docs/reference/` 按 marker 切 trial，只在 video 段做质检，并在 session 内把通过片段拼起来拟合一次 ICA。本工具每个 Parquet 单独检测、单独拟合，不做 session 或 video 工作流。参考目录是存档，不是执行入口。

默认陷波是单个 50 Hz，可以在配置里改。缺坐标不终止、不猜测位置。这时桥接检测改用电学距离近邻，这些通道不参与球面插值。标准模板不能按序号给缺失电极补位置。

## 发布与内部标记

坏道比例大于 0.60，或好道少于 4 个，则不发布。已发布记录的 `excellent` / `good` 分档见 README。`bad_rate < 0.30` 只是算法内部的 pass 标记，不是发布门槛。

## 不进入输出的计算

`hfnoise` 使用四阶 Butterworth、50 Hz 分界、SOS 前后向滤波。这条支路只算判定指标。

ICA 用同一份去直流数据的 1–100 Hz 副本拟合，高通为 `max(1 Hz, 配置高通)`，不串到输出支路。短于 5 秒或拟合失败则跳过，继续插值和平均参考。

## 有效性

结构质检通过、坐标文件齐全，都不表示帽型定位或生理有效性已验证。单位未声明时拒绝运行。暂定坐标只在显式传入 `configs/provisional.yaml` 时使用，来源和适用范围见 [PROVENANCE.md](PROVENANCE.md)。
