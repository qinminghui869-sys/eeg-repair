# 算法与实现边界

参数默认值见 [README](../README.md) 的处理参数表。阈值集中在 `algorithms.py`，不在配置里再写一套。

## 执行顺序

1. 只读接入 Parquet，校验配置、有限数值、时长和时间轴，并解析头皮导联与 montage。
2. 有阻抗文件时先读快照。判定不使用滤波后的波形，也不用幅值反推阻抗。
3. 头皮导联去直流。输出支路做带通和陷波，采样率不变。截止频率必须低于 Nyquist，超出安全范围的陷波点跳过。
4. 在滤波结果上做五规则，再并入阻抗坏道。
5. 坏道比例大于发布上限，或好道少于 4 个，则不发布。已发布记录按 README 写入 `excellent` / `good`。`bad_rate < 0.30` 只表示算法内部 QC pass，不是发布门槛。
6. ICA 用同一去直流数据的 1–100 Hz 副本拟合，高通为 `max(1 Hz, 配置高通)`，不串联到输出支路。失败则跳过，继续插值。
7. 只对有坐标的坏道做球面样条，再对全部头皮通道平均参考。辅助导联不变。
8. 恢复源单位和浮点类型，另存 Parquet 并回读。不另存坏道、ICA 或参数记录。

## 与参考流程的差异

参考文档包含 marker 对齐、trial 切分、仅 video 质检，以及在 session 内把通过片段拼起来拟合一次 ICA。本项目每个 Parquet 单独检测和拟合 ICA，不实现 session/video 工作流。参考原件在 `docs/reference/`，不是可执行入口。

默认陷波为单个 50 Hz，配置可改。缺少坐标的通道不终止处理，也不补猜位置；桥接检测改用电学距离近邻，这些通道不参与球面插值。标准 montage 是模板坐标，不能按序号给缺失电极补位置。

`hfnoise` 使用四阶 Butterworth、50 Hz 分界、SOS 前后向滤波。该支路只计算判定指标，不作为输出信号。

缺少厂家完整 128 通道实测坐标或低通道数真实样本、且单位未声明时，不对对应设备出具修复有效性结论。暂定坐标只用于显式试运行，见 `configs/provisional.yaml` 与 [PROVENANCE.md](PROVENANCE.md)。
